## 7. BUILD SPECIFICATIES VOOR CODEX

### Platform
- **VS Code webview extension** (HTML/CSS/JS)
- Resizable, full screen, mobile/tablet ondersteund
- Dark mode foundation

### Color Tokens (CSS variables aanbevolen)
```css
--bg-primary: #0E0F10;
--bg-secondary: #14161A;
--bg-tertiary: #171A1E;
--surface-panel: #1A1D22;
--surface-elevated: #1D2126;
--surface-card: #22272D;
--surface-inset: #262C33;
--border-soft: #313640;
--border-secondary: #3B4048;
--border-divider: rgba(255,255,255,0.06);
--text-primary: #F4EDE1;
--text-secondary: #D3CABD;
--text-supporting: #B8B0A4;
--text-muted: #948D83;
--accent-gold: #D6B35A;
--accent-gold-bright: #E2C774;
--accent-gold-deep: #C89B3C;
--glow-gold: rgba(214,179,90,0.28);
--glow-ivory: rgba(244,237,225,0.10);
```

### Typography
- Font family: Inter (primary), SF Pro Display/Text, Helvetica Neue fallback
- Headings: weight 600
- Section titles: weight 500-600
- Body: weight 400
- Labels/chips: weight 500

### Layout Zones (16:9 desktop, responsief)
1. **Top-left**: Budio logotype (ivory, minimal)
2. **Left rail (~20% width)**: Werk panel — Sprint, taken, priorities
3. **Center**: Jarvis intelligence core (radiale gouden ring-compositie)
4. **Right rail (~18% width)**: Awareness panel — signalen, status
5. **Above command bar**: Speaking surface (translucent floating banner)
6. **Bottom**: Command bar — input + context chip

### Surface Treatment
- Dark glass effect — translucente surfaces (80-85% opacity)
- GEEN harde rechthoekige borders
- Definitie door tonal separation + warm gold edge glow + thin gold accent lines
- Moderate rounded corners (16-24px)

### Animation Hints (uit de loop video)
- Core ringen: langzame rotatie op verschillende snelheden
- Gouden glow: subtiel pulserend
- Connector lijnen: zachte shimmer
- Warm lichtdeeltjes: traag driftend door de ruimte
- Speaking surface waveform: pulserend wanneer Jarvis "spreekt"
- Alle motion: extreem subtiel, ambient, "ademend"
